Confidence

A marker floats over each building. The letter is the lower of its location and form grades.

A, documented: survives, or measured and photographed
B, supported: a period photo or a specific description
C, inferred: reasoned from written sources
D, conjectural: known to exist; place or shape is a placeholder

About the model

Ground: USGS 2021 lidar, bare earth, so it includes today's railroad embankment, highway and gravel pits. Heights: measured from the 2021 lidar point cloud for surviving buildings, and read off the solved 1885 photographs for the Hotel de Mores, Roberts Hall and the Metropolitan. Other buildings use standard heights for their number of stories. See the method.

    Period photographs

    Choose a photograph to stand where the photographer stood. Matched views were solved from control points, so the model lines up with the photo. Fitted views were matched to a few points on one building, so they line up closely. Approximate views were set by eye and show the same scene from about the same place.
